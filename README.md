# Закрывающий тег

Финальный проект курса по вёрстке. Одностраничный сайт-ностальгия, который подводит итоги пути начинающего фронтенд-разработчика от нулевого спринта до последнего «закрывающего тега».

## 📄 Описание

Страница состоит из карточек, каждая из которых рассказывает об одном из этапов обучения:

- **Фритрек и нулевой спринт** — подготовка к работе;
- **1 спринт** — страх чистого листа и первые успехи;
- **2 спринт** — погоня за идеалом и поддержка близких;
- **3 спринт** — обходные стратегии и моменты, когда опускаются руки;
- **«Сейчас я здесь»** — финал пути и мысли о том, что вёрстка — это целый мир.

Каждую карточку можно «лайкнуть» — для этого предусмотрена анимированная SVG-иконка сердца с искрами. Внизу страницы есть кнопка «Сохранить на память», открывающая модальное окно с дискетой.
